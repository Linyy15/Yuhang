# 青柠风格起始页 · 设计草案（v0.1，草案 / 待确认）

> 定位：**借鉴青柠起始页的概念（整屏起始页 / 大时钟 / 居中搜索 / 可自定义快捷链接 / 壁纸 / 设置），但完全融入「屿航」现有视觉与组件体系**——不是粘进来一个外来的"青柠"页面，而是屿航自己的"整屏起始页"。
> 关系：与现有 `#intro` 个人主页式开场页 **并存可切换**，二者共享同一套极光背景 + 玻璃卡片 + 开场弹簧缓动视觉语言。

---

## 一、整体理念

- **视觉上它是屿航的一部分**：复用 `#intro` 已经建立的极光背景、玻璃卡片、强调色、开场弹簧缓动入场。主题（terminal / magazine / brutalism / cyber / pixel / swiss / glass / journal / space）与 7 种强调色切换时，起始页**同步变**——它继承整站的 `data-theme` 与 `--accent`。
- **功能上是青柠那类整屏起始页**：打开就是一屏干净的东西——大时钟、一句问候、一个搜索框、一排可自定义的快捷链接、可换壁纸。
- **与主站数据打通**：快捷链接区顶部以只读方式投影「收藏 / 最常访问 / 当前工作区」里的网站，下方是用户自己添加/排序的"常驻快捷"。搜索用顶栏那个**唯一的引擎选择器**，引擎切换双向同步。

## 三、视觉融入要点（和现有 #intro 属同一套语言）

| 要素 | 做法 |
|------|------|
| 背景 | 不复用自造渐变；起始页根元素**透出主站 `.bg` 极光层**，并在其上叠一层轻微暗角 + 可选壁纸（壁纸置于极光之下、半透明，被主题色调染色） |
| 卡片 | 快捷链接用屿航现有 `.card`/`.glass` 毛玻璃，微描边 + 浅投影，和主站卡片一致 |
| 图标 | 复用主站 favicon 多源回退（favicon.im → DuckDuckGo → Google → 首字），失败降级一致 |
| 颜色 | 全部走 `--accent`/`--accent-2`/`--glass-*`，无硬编码色；主题切换时整块跟着变 |
| 入场 | 沿用 `#intro` 的弹簧缓动 `cubic-bezier(.34,1.56,.64,1)` 缩放淡入；标题字母逐字弹簧 |
| 动效降级 | 尊重 `prefers-reduced-motion` 与主站 `data-perf=low/mid`：低端机/减少动态 时关闭入场弹簧、关闭极光流动、直接显示终态 |
| 字体/层级 | 时钟用主站同款 tabular-nums 细体大数字；问候、一言用主站正文层级 |

## 四、搜索与引擎（单一真相来源）

- **不再并行一列"引擎 pill"**：搜索框右侧直接嵌顶栏同款引擎下拉（站内 / 百度 / 谷歌 / 必应 / B站 / 知乎 / GitHub），就是主站 `#engine-btn`/`#engine-menu` 的那一套，引擎切换对两侧**同一个**生效（localStorage `nav_engine_v1` + `setEngine` 双向通知）。
- 输入：站内引擎时实时联想主站站点（名称模糊匹配，显示 favicon + 直达）；识别 URL 时给出"直达"。
- 回车：站内 → 把关键词交主站搜索框、关闭起始页、滚回主站卡片流；站外 → 新标签打开；URL 直达 → 新标签。

---

## 五、快捷链接（数据打通）

- **两段式**：
  1. **只读投影**：自动列出「收藏 / 最常访问 / 当前工作区」的网站（小尺寸、只读），跟着主站数据变化。
  2. **常驻快捷**：用户自己添加/编辑/删除/拖拽排序，存 `nav_startpage_v1`（`nav_` 前缀规范，与收藏/点击同构）。
- 编辑模式：进入后每个卡片右上角出现 ✕，＋ 添加，HTML5 拖拽重排。
- 默认预置 12 个热门站（B站/知乎/微博/百度/淘宝/京东/腾讯视频/网易云/GitHub/CSDN/豆瓣/抖音），首次进入出现，用户可删。

---

## 六、壁纸

- 4 种：**极光（默认，主站极光层）** / **海蓝** / **必应每日壁纸** / **暗夜**。
- 必应壁纸放在极光层之下、半透明染色；图源多回退，**离线自动回落极光**，不报错不跳转。
- 壁纸切换存 localStorage，记住选择。

---

## 七、与现有 #intro 的切换关系

- 设置里新增一项开关「起始页样式：个人主页 / 整屏」，或悬浮球双入口（🏝 起始页 = #intro；🍋 整屏起始页 = 本功能）。
- 二者**共享极光背景与开场动画节奏**，所以来回切不突兀。
- URL `#startpage` 可直达整屏起始页。
- 「进入导航」= 关闭起始页 + 平滑滚回主站卡片流（`#app`）。

---

## 八、实现层面（低侵入 / 可回退）

- 新增 2 个文件：`web/js/startpage.js`、`web/css/startpage.css`（独立、可整删回退）。
- 修改 `web/index.html`（挂 DOM/引用/悬浮球入口，纯追加）与 `web/js/app.js`（`setEngine` 内 1 行通知钩子），`web/sw.js`（缓存白名单 + 版本 +1）。
- 回退：`git checkout` 单文件 或 `git reset --hard 3d64dc7` 整仓恢复；另有 `backup-pre-startpage/` 副本。
- 不改动 `data/`、构建脚本、数据管线；单文件打包 `dist/index.html` 自动内联。

# 屿航 · 网站升级规格（Spec v1.6）

> 版本定位：在 v1.5 四页整体完善基础上，补齐“屿航 → 屿事 → 屿咪”的个人工作台能力。
> 适用范围：主站 `index.html`、待办页 `todo.html`、IP 页 `ip.html`、后台 `admin.html`。
> 文档状态：**未修改业务代码**，仅用于升级规划与后续执行核对。

---

## 一、核心原则

1. **少量用户优先**：优先服务现有少数核心用户，不做强制商业化、不做会员付费门槛。
2. **个人主页感优先**：保持“个人岛屿”定位，不做通用 SaaS 工具化堆砌。
3. **先补能力，再补包装**：优先补齐用户高频刚需（待办输入、番茄钟、提醒、角色成长）。
4. **本地优先**：默认仍以本地数据为主，不强制联网或订阅。
5. **可增量实现**：每轮只落地能直接验证的功能，避免一次性大改。

## 三、升级目标（P0 / P1 / P2）

### P0：核心体验补齐

目标：把“屿航”从“导航站”推进到“可日常使用的工作台”。

#### 1) 自然语言输入（待办）
- 现状：**已有基础**，代码中存在 `parseNaturalInput` 解析能力。
- 缺口：是否已完整暴露到输入框、是否支持稳定的一键解析、是否覆盖全部语法（优先级/日期/标签/重复）需要继续核对。
- 目标：让用户一句话直接创建待办，减少手工填表。

#### 2) 完成率趋势图
- 现状：**未实现**。
- 缺口：当前只有实时计数，没有按周 / 按天的完成率趋势。
- 目标：展示近期完成率走势，帮助用户看清执行节奏。

---

### P1：任务与节奏管理补齐

#### 3) 重复任务
- 现状：**未实现**。
- 缺口：待办不支持 daily / weekly / monthly 等重复项。
- 目标：让常见固定事项可自动循环。

#### 4) 番茄钟
- 现状：**未实现**。
- 缺口：屿事缺少内置计时与专注模式。
- 目标：提供 25/5 或 50/10 番茄钟，提升执行完成率。

#### 5) 提醒
- 现状：**未实现**。
- 缺口：没有到点提醒、逾期提醒、即将到期提醒。
- 目标：提供最小可用提醒机制，减少遗忘。

#### 6) 日历视图
- 现状：**未实现**。
- 缺口：待办只有截止日期字段，没有月历 / 周历视图。
- 目标：让用户按日期查看任务分布。

#### 7) 访问频次统计面板
- 现状：**未实现**。
- 缺口：主站缺少“最常访问 / 本月访问量 / 热度趋势”等可见统计。
- 目标：展示用户实际使用情况，辅助决策和回顾。

---

### P2：角色、世界观与个性化增强

#### 8) 世界观故事
- 现状：**未实现**。
- 缺口：屿咪页没有独立世界观、背景设定、角色来源说明。
- 目标：让角色更有连续性，提升用户情感黏性。

#### 9) 角色成长系统
- 现状：**未实现**。
- 缺口：没有等级、积分、成就、解锁表情、解锁台词等成长结构。
- 目标：让屿咪具备可积累的互动成长感。

#### 10) 壁纸 / 背景换肤
- 现状：**未实现**。
- 缺口：当前没有壁纸库、上传壁纸、固定背景管理等能力。
- 目标：增强主站和起始页个性化。

#### 11) 快捷链接拖拽排序
- 现状：**未实现**。
- 缺口：当前缺少快捷链接持久化排序能力。
- 目标：支持用户在起始页或快捷区调整顺序并保存。

#### 12) 粉丝社区 / UGC
- 现状：**未实现**。
- 缺口：没有粉丝故事、评论、上传内容等公开互动区。
- 目标：仅作为可选增强，不做强制商业化。

#### 13) 语音 / 角色扮演对话
- 现状：**未实现**。
- 缺口：没有语音合成、对话回复、角色人格化交互。
- 目标：作为后续增强项，保持可选、轻体验，不做重 AI 商业包装。

## 五、非强制商业化说明

本 spec 明确说明：

- **不设置强制会员制**
- **不设置强制付费门槛**
- **不设置强制登录才能使用核心功能**
- **不做广告变现导向的功能改造**
- **不做强制导流或营销弹窗**

允许保留的轻量增强项仅限于：

- 本地数据管理
- 可选备份 / 导出
- 可选分享 / 反馈
- 可选社区内容（若未来加入，也只作为自愿参与）

## 六、建议执行顺序

1. 先补齐 **自然语言输入完整体验**
2. 再做 **完成率趋势图**
3. 再做 **重复任务 / 提醒 / 日历**
4. 随后补 **番茄钟**
5. 最后补 **角色成长系统 / 世界观 / 壁纸 / 快捷链接排序**

## 八、结论

当前项目已经具备：

- 主页
- 待办页
- IP 页
- 后台
- 同站入口
- 基础本地数据能力

但距离“屿航 = 个人工作台”的目标，仍缺少：

- 自然语言输入完整体验
- 完成率趋势
- 重复任务
- 番茄钟
- 提醒
- 日历视图
- 访问频次统计
- 角色成长与世界故事
- 壁纸 / 快捷链接 / UGC 等个性化增强

因此，本 spec 的定位是：**在保持少量用户、非强制商业化的前提下，把屿航补成可长期使用的个人工作台。**

# 🏝️ 屿航 · 探索每一座数字岛屿

一个本地优先的网址导航网站：极简展示风 + 极光背景 + 毛玻璃卡片，多标签分类导航。每一个网站都是一座数字小岛，这里是你的航行起点。

## 怎么运行

**最简单**：双击打开 `web/index.html`（用 Chrome / Edge 浏览器），无需安装任何东西、无需本地服务。

后台管理页：双击打开 `web/admin.html`（纯本地，编辑数据后导出下载替换）。

## 怎么改数据

### 方式一：后台管理页（推荐，无需命令行）

1. 双击打开 `web/admin.html`
2. 站点列表直接编辑 / 新增 / 删除；顶部可搜索过滤（**模糊匹配增强**），校验面板会标出空网址、重复网址、缺简介等问题；**列表分页**（每页 10/20/50，页码窗 + 上下页），手机端自动转为 3 列迷你卡片
3. **批量操作**：勾选多行（或表头全选）→ 批量删除 / 批量改标签 / 批量改大类；删除可**撤销**；支持按名称/大类**排序**、复制网址、**双击行快速编辑**；所有操作有 **Toast 提示**
4. 点「💾 保存到 sites.js（写入文件）」：**真正把数据写入 `web/data/sites.js`**——HTTPS/localhost 下用 File System Access API 直接写入文件（保存框选 `web/data` 目录即可）；**file:// 双击打开时浏览器禁止网页写文件**，此时会下载 sites.js 并提示用本地服务（如 `npx serve web`）打开后即可直接写入；若部署过 PWA，数据已走「网络优先」，刷新主站即可看到修改（仍显示旧数据时 Ctrl+F5）
5. 刷新 `web/index.html` 即可看到新数据
6. 如需 Excel 二次编辑：点「导出 sites.tsv」→ 编辑 → 用 `node scripts/build.mjs` 重新生成

### 方式二：直接改 tsv + 命令行

1. 编辑 `data/sites.tsv`（用 Excel 或记事本，保持 8 列：简称 / 详细名称 / 大类 / 标签 / 简介 / 详细简介 / 网址 / 是否需要加速器）
2. 在项目根目录运行：`node scripts/build.mjs`
3. 刷新 `web/index.html` 即可看到新数据

## 登录与云同步（Supabase）

- 项目配置在 `web/js/config.js`（URL + anon 公钥，公开安全；`service_role` 密钥绝不进前端）
- 表结构 / RLS / 统计函数：`scripts/supabase-schema.sql`（已在 Supabase 控制台执行）
- 隐私模型：每个账号数据行带 `user_id`，RLS 保证仅本人可见；全站排行榜只读聚合（`get_site_stats` RPC），不暴露个人明细
- **「我的网站」是账号绑定的个人数据**：新增/编辑后自动推送到云端 `personal_sites` 表，任意设备登录同一账号即自动拉取恢复（非仅浏览器本地）
- 设置里的「分享统计」开关：关闭后收藏/点击只留在本地，不参与云同步与排行榜

### 站长查看用户反馈（后台管理页）

后台管理页的「📣 反馈记录」面板可查看所有用户提交的网站反馈（含提交者邮箱、时间），并可删除已处理的反馈。

- 权限模型：新增的 `get_all_feedback()` / `delete_feedback()` 两个 SECURITY DEFINER 函数在服务端校验**站长 JWT 邮箱**（默认 `xvwang99@126.com`），非站长调用返回空，普通用户仍只能看自己的反馈
